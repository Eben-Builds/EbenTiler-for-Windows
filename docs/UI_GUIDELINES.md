# EbenTiler UI Guidelines

EbenTiler의 설정 UI와 랜딩페이지는 단순한 장식보다 명확한 정보 구조와 일관된 Windows 경험을 우선합니다.

## 선택 상태

- 선택된 사이드바 항목이나 탭은 **배경색 변화 + 아이콘/텍스트 색상 변화**로만 강조합니다.
- 선택 표시를 위해 별도의 **세로바, 가로바, 밑줄, 사이드 레일, 상단/하단 스트립**을 추가하지 않습니다.
- 의미 없는 강조선은 AI 생성 UI처럼 보이기 쉬우므로 사용하지 않습니다.
- 선은 표 경계, 구분선, 입력 경계처럼 실제 구조를 설명할 때만 사용합니다.

## 아이콘

- 문자 기호 대신 가능한 한 일관된 벡터 아이콘을 사용합니다.
- 아이콘은 메뉴 의미가 즉시 이해되는 형태를 선택합니다.
- 동일한 스트로크 두께와 시각적 밀도를 유지합니다.
- 아이콘 자체를 과도하게 단순화하거나 추상화하지 않습니다.

## 표면과 강조

- 기본 화면은 밝은 Canvas와 흰색 Surface를 유지합니다.
- 강조색은 선택 상태, 주요 버튼, 핵심 상태에만 제한적으로 사용합니다.
- 불필요한 그라데이션, 네온, 장식용 선은 사용하지 않습니다.

## 변경 원칙

- 기존 기능과 구조를 유지하면서 필요한 부분만 수정합니다.
- 시각적 변화는 실제 Windows에서 100%, 125%, 150% 배율로 확인합니다.
- UI 변경 후 빌드와 설치/제거 검증을 통과해야 합니다.
