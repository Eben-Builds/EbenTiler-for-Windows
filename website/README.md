# EbenTiler 랜딩페이지

이 폴더는 EbenTiler 공식 랜딩페이지의 정적 소스입니다. 별도 서버나 데이터베이스 없이 정적 호스팅에서 동작합니다.

## 구성

- `index.html`: 랜딩페이지 본문
- `styles.css`: 전체 디자인과 반응형 스타일
- `hero-visual.svg`: 테두리 없이 자연스럽게 연결되는 히어로 그래픽
- `app.js`: 다운로드 버튼의 간단한 상태 표시
- `favicon.svg`: 창 배치 동작을 표현한 EbenTiler 전용 파비콘
- `_headers`: 정적 호스팅용 보안 헤더

## 다운로드 파일

페이지의 모든 `윈도우용 다운로드` 버튼은 같은 배포 폴더의 `EbenTiler-Setup.exe`를 내려받습니다.

저장소 소스에는 실행 파일을 중복 보관하지 않고, `.github/workflows/build-website.yml`이 최신 설치 프로그램을 빌드한 뒤 랜딩페이지와 한 묶음으로 만들어 줍니다. 따라서 이 배포 묶음을 정적 호스팅에 올리면 다운로드 버튼이 실제 설치 파일을 바로 내려받습니다.

## 로컬 확인

최신 설치 파일을 `website/EbenTiler-Setup.exe` 위치에 복사한 뒤 정적 서버로 이 폴더를 열면 다운로드 버튼까지 확인할 수 있습니다.
