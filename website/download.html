설치 전에
이 화면만 확인해 주세요.

Tessdeck은 현재 코드 서명 절차를 준비 중이라 처음 실행할 때 Windows의 “PC 보호” 화면이 표시될 수 있습니다. 놀라지 않도록 실행 방법을 먼저 안내합니다.

✓
왜 경고가 표시되나요?

현재 공개 설치 파일에 Authenticode 코드 서명이 아직 적용되지 않아 Windows가 게시자를 확인하지 못할 수 있기 때문입니다. 이 경고 자체가 악성 프로그램이라는 뜻은 아닙니다.

PC 보호 화면이 나오면 이렇게 하세요.

파일 이름과 출처를 확인한 뒤 아래 순서로 진행합니다. Tessdeck v1.1.0부터 설치 파일 이름은 Tessdeck-Setup.exe이며, 이전 v1.0.1 릴리스는 기존 브랜드명으로 보관됩니다.

1

Tessdeck-Setup.exe 실행

다운로드한 설치 파일의 이름이 Tessdeck-Setup.exe인지 먼저 확인합니다.

2

“추가 정보” 클릭

Windows의 PC 보호 화면이 표시되면 화면 안의 추가 정보를 누릅니다.

3

확인 후 “실행” 클릭

앱 이름과 파일 출처를 확인한 뒤 실행을 누르면 설치를 계속할 수 있습니다.

파일 확인

무결성이 궁금하다면 SHA-256도 확인할 수 있습니다.

GitHub Release에는 설치 파일과 함께 SHA-256 체크섬 파일을 제공합니다.
